# گردآفرید (Gordafarid) 🛡🌸

ربات پیشرفته، سریع، امن و کاملاً فارسی مدیریت و امنیت گروه‌های تلگرامی، توسعه داده شده با زبان **Rust** و پایگاه داده **PostgreSQL**.

---

## 🌟 ویژگی‌های کلیدی

1. **سیستم دستورات سه‌گانه جهانی (Universal Command Engine):**
   - پشتیبانی کامل از دستورات متنی فارسی بدون اسلش (مثل `بن`, `میوت`, `اخراج`, `اخطار`, `پاکسازی ۲۰`, `قوانین`, `راهنما`).
   - پشتیبانی از دستورات ریپلای هوشمند با پارس مدت‌زمان فارسی (مانند `بن ۱ ساعت تبلیغات`, `میوت ۳۰ دقیقه اسپم`).
   - پشتیبانی از دستورات استاندارد اسلش تلگرام (`/ban`, `/mute`, `/help`, `/settings`).
   - نرمال‌سازی خودکار حروف عربی، کشیدگی‌ها، اعراب و ارقام فارسی/عربی (`۰-۹` به `0-9`).

2. **کاملاً رایگان و بدون قفل پرداخت:**
   - هیچ پلن اشتراکی یا پولی (VIP/Pro) وجود ندارد.
   - تمامی امکانات برای تمامی گروه‌ها به صورت نامحدود در دسترس است.

3. **رابط کاربری ۱۰۰٪ فارسی:**
   - تمامی پیام‌ها، پنل دکمه‌های شیشه‌ای، اعلان‌های مجازات و گزارش‌ها به زبان شیرین فارسی هستند.

4. **امنیت، پایداری و کارایی فوق‌العاده:**
   - توسعه داده شده با **Rust** و فریم‌ورک هم‌روند **Tokio**.
   - مصرف حافظه رم ناچیز (حدود **۳۰ الی ۵۰ مگابایت**) در مقایسه با ربات‌های پایتونی.
   - پایگاه داده رابطه‌ای **PostgreSQL** نصب‌شده به صورت محلی با امنیت و ایزولاسیون کامل.
   - لایه کش فوق‌سریع در حافظه (`DashMap`) برای بررسی رگباری پیام‌ها بدون فشار به دیتابیس.

5. **امکانات ضداسپم و مدیریت گروه:**
   - سیستم ضداسپم / ارسال رگباری (Anti-Flood) بر اساس پنجره لغزان زمانی.
   - فیلتر هوشمند لینک و تبلیغات با امکان تعریف دامنه‌های مجاز (Whitelist).
   - دو لیست مستقل کلمات ممنوعه (حذف پیام، اخطار + حذف پیام).
   - فیلتر پیام‌های فوروارد، استیکر و رسانه.
   - سیستم تایید هویت عضویت (کپچا) با دکمه شیشه‌ای برای مسدودسازی ورود ربات‌های مخرب.
   - پاکسازی دسته‌جمعی پیام‌ها (`پاکسازی ۲۰`).
   - سیستم اخطار هوشمند با قابلیت تشدید مجازات (Escalation) به میوت خودکار.
   - سیستم زمان‌بندی پس‌زمینه پایدار (رفع خودکار بن و میوت حتی پس از ری‌استارت سرور).

## 📁 ساختار پروژه

```
gordafarid/
├── Cargo.toml                  # تنظیمات و وابستگی‌های پروژه Rust
├── migrations/
│   └── 0001_initial_schema.sql # جداول پایگاه داده PostgreSQL
├── src/
│   ├── main.rs                 # نقطه ورودی، راه‌اندازی DPTree و شنود رویدادها
│   ├── config.rs               # بارگذاری متغیرهای محیطی
│   ├── errors.rs               # خطاهای ساخت‌یافته با پیام‌های کاربرپسند فارسی
│   ├── db/                     # تعامل با پایگاه داده PostgreSQL
│   ├── engine/                 # موتور نرمال‌سازی فارسی، پارس مدت‌زمان و احراز هویت
│   ├── handlers/               # هندلرهای پیام، دستورات، فیلترها و دکمه‌های شیشه‌ای
│   ├── services/               # کش در حافظه و زمان‌بندی کارهای پس‌زمینه
│   └── ui/                     # پیام‌های فارسی و کیبوردهای اینلاین
├── backup.sh                   # اسکریپت پشتیبان‌گیری خودکار
├── restore.sh                  # اسکریپت بازگردانی پشتیبان
└── gordafarid.service          # فایل سرویس systemd برای استقرار در لینوکس
```

## 🚀 راهنمای نصب و راه‌اندازی روی سرور لینوکس

### ۱. پیش‌نیازها
- پایگاه داده PostgreSQL
- کامپایلر Rust (Cargo)

### ۲. تنظیم متغیرهای محیطی
فایل `.env` را در پوشه پروژه ایجاد یا ویرایش کنید:
```env
TELOXIDE_TOKEN=your_bot_token_from_botfather
DATABASE_URL=postgres://gordafarid:your_secure_password@localhost:5432/gordafarid
OWNER_ID=your_telegram_user_id
RUST_LOG=info
```

### ۳. کامپایل نسخه انتشار (Release)
```bash
cargo build --release
```

### ۴. فعال‌سازی سرویس خودکار با Systemd
```bash
sudo cp gordafarid.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gordafarid.service
```

### ۵. مشاهده لاگ‌های زنده ربات
```bash
journalctl -u gordafarid.service -f
```
